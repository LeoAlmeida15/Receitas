[title](Site de Receitas)
A ideia é ser um site onde os usuários possam criar uma conta e salvar todas as suas receitas em um só lugar. Em cada receita, o usuário poderá colocar informações como o nome, os ingredientes, o modo de preparo, o tempo de preparo e a categoria, deixando tudo organizado e fácil de encontrar. O objetivo é facilitar na hora de cozinhar, sem precisar procurar receitas em vários sites ou anotações. Assim, cada usuário terá seu próprio livro de receitas salvo e poderá acessar suas receitas de forma rápida e prática.

O que vai poder ser feito pelo usuário: cadastro, cadastrar receitas, editar receitas, excluir receitas, colocar os ingredientes e o modo de preparo, informar o tempo de preparo, escolher a categoria da receita, adicionar uma imagem, criar pastas de receitas para separar de forma organizada, pesquisar receitas e também cadastrar receitas próprias.
